# Herminio web

Rediseño del sitio de la Escuela Herminio Almendros. El proyecto cuenta con una dirección de identidad y una propuesta gráfica estática; todavía no hay una aplicación de producción ni una decisión final de framework.

## Prototipo

[`propuesta-visual/`](propuesta-visual/) implementa el mensaje **“Aquí, cada niña y niño descubre el mundo, no lo memoriza”** en una portada estática responsive. Su contenido pedagógico, paleta y tipografía siguen sujetos a validación antes de convertirse en sitio de producción.

[`propuesta-visual-anterior/`](propuesta-visual-anterior/) conserva el prototipo previo completo para comparación.
